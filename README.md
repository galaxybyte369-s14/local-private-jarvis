# local-private-jarvis 🦾

A 100% local, completely private AI desktop assistant built on a Llama model base. This application combines local LLM inference with a custom graphical interface to create an offline chitchat companion that references user-defined context directly from its root text files.

## ✨ Features
- **Floating Overlay Icon:** A custom floating desktop icon for quick, convenient access.
- **Dedicated Chat Window:** A clean graphical user interface for seamless interaction.
- **Text-to-Speech (TTS):** Jarvis speaks his responses back to you in real-time.
- **Root-Level Knowledge Base:** Securely references permanent personal data structured in bullet points directly inside its local source directories, rather than logging active chat history.

## 📁 System Requirements & Optimization
This project is built and optimized to run efficiently on lightweight, hardware-constrained environments without requiring paid cloud APIs.

## 🚀 How to Run
1. Open your terminal.
2. Navigate to this project folder.
3. Run the main launch script:
   ```bash
   python jarvis.py
   ```
*(Note: You will need to download your preferred Llama model weights separately and place them in your local directory as specified by your configuration files).*
